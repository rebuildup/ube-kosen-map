# 3Dキャンパスモデル 公開データポリシー

`src/campus3d/` 以下のデータが公開Gitリポジトリに含まれることを前提に、出典ごとの公開可否を分類する。UIでの非表示・opt-in・別モジュール化・tree shaking は公開Gitソースからの情報隠蔽を保証しないため、**公開してよいデータだけをリポジトリに置く**ことを境界とする。

## 分類

### 公開可（public contract）

| データ | 出典 | 根拠 |
| --- | --- | --- |
| 地形レイヤー・地表面高さ | campus-map.svg ベースレイヤー `_00`〜`_08` | 2Dマップの公開アセット由来 |
| 地面線画（tlines）とその分類 | 同上 | 同上 |
| 建物の外形・各階の床/壁セグメント | campus-map.svg 収録の平面 | 同上 |
| 建物レジストリ（名称・階数・色・カテゴリ） | 学校HP・学生便覧の建物一覧 | 公開情報 |
| 学校棟の部屋「種別」名（講義室・実習室など、番号なし） | 学生便覧の平面図 | 学校発行の配布資料。番号は含めない |
| 座標変換・較正定数 | 本リポジトリの2DマップとHP地図の照合 | 再計算可能 |

### 公開不可（restricted）

| データ | 出典 | 理由 |
| --- | --- | --- |
| 寮の部屋番号（21xx〜91xx 系） | 寮生手帳の棟別平面図 | 施設管理上の内部情報。居住者の部屋を特定しうる |
| 寮の内部区画プラン（壁・区画の幾何） | 同上 | 同上。外観（外形・階数・屋根）までが公開範囲 |
| 個人の所在ピン（居室・教室・研究室） | 本人の説明・記憶 | 個人情報 |
| 寮生手帳由来の棟の内部記述 | 同上 | 上記に準ずる |

補完4棟（E棟・B棟・C棟・浴場棟）の**外形**は学生便覧の建物配置図トレースであり公開可。**内部区画**は寮生手帳由来のため restricted。

## 実装上の境界

- `campusModelData.ts`: 寮の `fl`（内部平面）を含めない。ryod の 2F は campus-map.svg 収録の公開平面のみ。
- `buildingRegistry.ts`: 寮エントリの `rooms`/`note` は部屋番号・手帳ページ引用を含めない。個人ピン（`PIN_DEFINITIONS`/`HUB_INFO`）は公開レジストリに置かない。
- 将来 restricted データを使う派生モデルが必要な場合は、公開Gitの外（例: git管理外の `data-private/` または private リポジトリ）に原本を置き、公開用データへの変換を別工程とする。`/data-private/` は `.gitignore` 済み。
- 機械検査: `campus3d.test.ts` の公開範囲ガードが、寮部屋番号パターンと手帳引用の混入を拒否する。

## 既知の残存リスク（要user判断）

- `feat/campus-3d-model` ブランチと `public/campus-3d.html`（PR #20 でclose済み）は、部屋番号入りの寮プランを含むまま公開Git上に残っている。履歴書き換え・ブランチ削除は破壊的変更のため、実施には明示的承認が必要（選択肢と影響は `docs/public-release-review.md` 参照）。本ポリシーは新規公開経路にのみ適用する。
- 学校棟の部屋「番号」（11番教室など）は教室表示として公開慣行上問題ないと判断したが、より厳格にする場合は番号表記の除去を検討する。
