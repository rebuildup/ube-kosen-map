# データ出典と公開方針

このドキュメントは、リポジトリに含まれる地図データ・アセットの出典と、
公開にあたっての注意事項を記録する。

## 収録アセット

| パス | 内容 | 出典 |
| --- | --- | --- |
| `public/campus-map3.svg` | キャンパス全体図（インラインSVGとして描画） | 宇部高等専門学校が公開している構内図をもとに作成 |
| `src/data/buildings.ts` | キャンパス地図のviewBox範囲 | `campus-map3.svg` のviewBoxから抽出 |
| `src/data/floorConfig.ts` | 建物ごとのフロア構成・SVGグループID | 同上 |
| `src/data/mapAmenities.json` | トイレ・ごみ箱などの設備ポイント | 構内図上の位置を手作業でプロット |
| `public/icon.svg` | ファビコン | このプロジェクトで作成 |

## 出典に関する前提

- 地図の元データは、宇部高等専門学校が公開している構内図・関連資料に基づく。
- 座標系はSVGのviewBox座標であり、実世界の測量座標ではない。
- 設備ポイントの位置は概略であり、最新の公式情報と差異がある場合がある。

## 収録していないもの

- 寮の部屋番号・内部レイアウトなど、個人の居住情報に関わり得る詳細データ
- 学生便覧・寮生手帳などの配布資料PDF/Illustratorファイル（開発参照用であり、
  公開リポジトリには含めない）
- 高専祭・コミケ関連の過去データ（イベント・展示・模擬店）

## Git履歴について

過去のコミットには、現在は削除した参照資料（`docs/reference/`）や
祭関連アセットが含まれている。履歴の書き換えは公開リポジトリでは
破壊的変更となるため行っていない。機微情報が履歴に残る場合の対応は
別途判断が必要。

## 利用上の注意

- 本マップは非公式のファンメイドツールであり、学校公式の見解を示すものではない。
- 正確な施設情報・イベント情報は学校の公式発表を確認すること。
